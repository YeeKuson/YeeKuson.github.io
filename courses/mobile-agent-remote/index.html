课程导读

这是一篇碎碎念，飞书版与微信版使用同一份正文。

这节是我在 WorkBuddy 时发现了一个很有意思的功能：助理，也就是手机遥控，没错，就是今年年初openclaw火的时候那个：用手机就能操控AI的功能。

它可以把电脑上的 WorkBuddy 接到微信、企业微信、QQ、钉钉、飞书等消息工具里。腾讯官方的解释很直接：你在手机上发一条消息，电脑上的 WorkBuddy 执行任务，再把结果回复到手机上。

说白了，以后临时想让 Agent 干点什么，不一定非得重新坐回电脑前。

微信最简单，扫码就行

如果你只是想体验一下，我建议先用微信。

打开 WorkBuddy 左下角头像，进入：设置 → 助理设置 → 微信助理。然后用微信扫码绑定即可。
